## Aufnahmefreigabe: Was tatsächlich sichtbar sein muss

**T3:** Der New-Jersey-Fall zeigt im gelieferten Sample 140 Adressen. Vor dem Wirksamkeitsdatum lautet der Status „Not yet effective“, danach gilt die extrahierte landesweite Regel. Das ist keine Behauptung, dass diese Gebäude gegen das Gesetz verstoßen.

**Los Angeles:** A0107 darf als lokaler Fall nur gezeigt werden, wenn seine rechtliche Stadtzuordnung belegt ist. Bei fehlendem Geonachweis wird das Problem behoben oder die örtliche Demo ausgelassen. „Los Angeles“ als Postort ist kein Ersatzbeleg.

**Belegsimulation:** Der hypothetische Zertifikatstag wird als Simulation markiert. Er löst nur die Datumsbedingung. Unbekannte Ausnahmen bleiben unbekannt; keinen vollständigen grünen Bescheid inszenieren.

**Rights card:** Zeigt das Ergebnis aus Originaldaten. Die Simulation wird nicht geteilt. EN/ES ist eine assistierte Übersetzung; der englische Quelltext ist maßgeblich.

**Extraktion:** Das öffentliche Regelpaket stammt derzeit aus `codex_assisted_extraction`. Den gesonderten API-Compiler nur dann als ausgeführten Lauf zeigen, wenn dazu ein tatsächlicher erfolgreicher Lauf mit Protokoll existiert. Ein Dry Run ist keine Extraktion.
